# Audit synthesis

- Best long-term destination: FLO website, because it avoids the Amazon warning, controls the offer, supports subscription, and captures the customer relationship.
- Best immediate destination: TikTok Shop, because the website checkout has material pricing, cadence, policy, portal, branding, and attribution defects.
- Amazon Pay on the website improves convenience but does not create an Amazon marketplace order or help remove the Amazon return badge.
- Launch gate for website traffic: offer consistency, live portal, working policies, Feels Like Om checkout identity, and verified TikTok purchase attribution.
- Site implementation is complete locally. Stripe remains the launch gate because the current production environment still pre-fills `WELCOME20`, and the existing subscription link does not match the promised six-month cadence.
- Use a fixed $54.99 discount to land exactly at $80. A literal 40% discount lands at $80.99.
- Do not force account registration. Stripe should collect the required order email; any marketing signup must be optional and explicit.
